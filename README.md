# KrishiMitra – Smart Agriculture Assistant

KrishiMitra is a smart agriculture application designed to help farmers access crop recommendations, weather information, plant disease detection, market prices, government schemes, and agricultural assistance in one place.

## Features

- **Crop Recommendation:** Suggest crops based on soil and climate information.
- **Weather Updates:** Access weather information to support farming decisions.
- **Plant Disease Detection:** Upload a leaf image to explore the disease-detection feature.
- **Market Prices:** View agricultural market price information.
- **Government Schemes:** Find information about relevant farming schemes.
- **AI Chatbot:** Get assistance with agricultural questions.
- **Multilingual Interface:** Designed to support English, Kannada, and Hindi.

## Technology Stack

- Frontend: React and Vite
- Styling: Tailwind CSS
- Backend: Python and FastAPI (if included in your current version)
- Authentication and hosting: Firebase (where configured)
- APIs and libraries: Refer to the project dependencies and configuration files.

## Getting Started

1. Clone this repository:
   ```bash
   git clone https://github.com/TejaswiniCA/KrishiMitra-Smart-Agriculture-Assistant.git
   ```
2. Open the project folder:
   ```bash
   cd KrishiMitra-Smart-Agriculture-Assistant
   ```
3. Follow the installation instructions in the frontend and backend directories. Install dependencies using the package and requirements files provided in the project.
4. Configure any required API keys and environment variables locally. Do not commit secrets to GitHub.

## Project Purpose

The goal of KrishiMitra is to make useful agricultural information more accessible and support farmers in making informed decisions.
